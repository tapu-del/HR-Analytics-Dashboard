# HR Analytics Dashboard

## Project Overview
Built an interactive HR Analytics Dashboard in Power BI to analyze employee data including headcount, attrition, salary, and demographics.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)

## Key Metrics
- Total Employees: 1,470
- Active Employees: 1,233
- Exited Employees: 237
- Average Salary: 6.50K

## Dashboard Features
- 4 KPI Cards (Total Employees, Active, Exited, Average Salary)
- Bar Chart: Employees by Department
- Pie Chart: Employees by Gender
- Donut Chart: Employees by Age

## Key Insights
1. Research & Development has the most employees
2. Male employees (54%) slightly higher than Female (46%)
3. 237 employees exited (about 16% attrition)
4. Average monthly salary is 6.50K
